MODULE 1: Vision & OCR Pipeline

Primary Files: app/vision_ocr.py (244 lines) and scripts/generate_mock_data.py (142 lines)

1. Image Ingestion Without Disk I/O (Lines 44–80)

def load_image(self, image_input: Union[str, bytes, np.ndarray]) -> np.ndarray:
    if isinstance(image_input, bytes):
        nparr = np.frombuffer(image_input, np.uint8)
        img = cv2.imdecode(nparr, cv2.IMREAD_COLOR)
        return img

Tradeoff: By decoding raw memory buffers using cv2.imdecode, we bypass saving temporary files to disk, eliminating I/O latency and disk garbage collection on an edge device.

2. Outer Geometry & Dimensional Deviation (Lines 82–119)

gray = cv2.cvtColor(bgr_img, cv2.COLOR_BGR2GRAY)
_, thresh = cv2.threshold(gray, 75, 255, cv2.THRESH_BINARY)
contours, _ = cv2.findContours(thresh, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
main_contour = max(contours, key=cv2.contourArea)
contour_area = cv2.contourArea(main_contour)
bx, by, bw, bh = cv2.boundingRect(main_contour)
solidity = contour_area / float(bw * bh)
aspect_ratio = float(bw) / float(bh)

# Mathematical Threshold:
if solidity < 0.96 or aspect_ratio < 0.85 or aspect_ratio > 1.15:
    return "dimensional_deviation", 0.95, metrics

Heuristic: Solidity ($\text{Area} / \text{BBox Area}$). A nominal square CNC machined billet has $\text{Solidity} \approx 0.994$. When a corner is sheared or flange warped, solidity drops to $0.922$, deterministically classifying dimensional_deviation.

3. Central Machining ROI Surface Inspection (Lines 120–158)

# Central inspection zone avoiding stamping pads & mounting holes
roi_y1 = int(by + bh * 0.28)
roi_y2 = int(by + bh * 0.82)
roi_x1 = int(bx + bw * 0.15)
roi_x2 = int(bx + bw * 0.85)
roi = gray[roi_y1:roi_y2, roi_x1:roi_x2]

blurred_roi = cv2.GaussianBlur(roi, (3, 3), 0)
edges = cv2.Canny(blurred_roi, 50, 150)
edge_pixels = cv2.countNonZero(edges)

if edge_pixels < 50:
    return "no_defect", 0.98, metrics
elif edge_pixels < 450:
    return "surface_scratch", 0.92, metrics
else:
    return "crack", 0.96, metrics

Mathematical Calibration:

  • Clean surface edge pixels: 0 $\rightarrow$ no_defect
  • Thin linear scratch: 207 pixels $\rightarrow$ surface_scratch
  • Thick branching crack: 732 pixels $\rightarrow$ crack
