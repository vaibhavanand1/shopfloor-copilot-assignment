# SOP-ENG-02: Rework vs. Scrap Disposition Decision Matrix

## 1. Defect Disposition Hierarchy
Every rejected component must be formally dispositioned into one of two operational categories: authorized Rework or terminal Scrap. Operators must never perform unauthorized spot-grinding or bench modifications.

## 2. Surface Scratch Rework Routing
Parts flagged with superficial surface scratches (< 0.5 mm depth) are assigned disposition code RWK-SURF. The operator must attach a yellow traveler tag and transfer the component to Station B-4 (Secondary Deburring & Polishing). Station B-4 technicians will buff the affected surface with Scotch-Brite maroon pads and re-measure thickness before releasing the component back to final inspection.

## 3. Structural Crack Scrap Protocol
Components exhibiting visual or verified cracks must immediately receive disposition code SCRP-CRK. Cracks represent compromised metallurgical integrity that cannot be remedied through post-processing. The part must be spray-marked with orange indelible ink, placed into the locked Red Quarantine Bin, and flagged for SCRAP in the ERP traveler.

## 4. Dimensional Deviation Disposition Rules
When a component exhibits a dimensional deviation, the line operator must check the active batch run status. If the measured variance exceeds 0.2 mm over nominal tolerance, the part cannot be salvaged through secondary skimming and must be flagged for SCRAP. The CNC operator must halt the milling cycle, inspect tool offset wear, and notify the shift lead.
